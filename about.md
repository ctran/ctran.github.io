I'm Cuong Tran, a software engineer at ServiceNow based in San Diego, CA.

## What I work on

- **Open source.** I maintain [annotate_models](https://github.com/ctran/annotate_models), which annotates Rails classes with schema and routes info, and [TinyRadius](https://github.com/ctran/TinyRadius), a small Java Radius library originally written by Matthias Wuttke.
- **Developer tooling.** I package prebuilt binaries for Nix in [nixpkgs-bin](https://github.com/ctran/nixpkgs-bin).
